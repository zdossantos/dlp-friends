## Regroupements et limites de fidélité

Les pages de lecture partagent une composition, avec FAQ dépliable, chronologie des nouveautés, étapes du matching et sommaire légal. Les textes juridiques et les nouveautés sont des extraits de démonstration : conserver les catalogues et données SSR existants lors de la réalisation. Les auth ont des champs spécifiques ; les événements secondaires sont représentés comme panneaux sur la liste, sauf la discussion. Les listes administratives partagent cartes mobiles / tables bureau, avec champs et actions propres au domaine. Les confirmations sont accessibles depuis leur action, pas uniquement depuis une planche de composants.

Le prototype utilise des initiales explicitement fictives à la place des images privées du catalogue. Aucun avatar additionnel ni photo personnelle ne fait partie de la proposition. Le tutoriel parcourt les cinq étapes après profil, sans créer de donnée sociale. Le compte de revue donne accès aux trois espaces uniquement pour consulter les maquettes : ce n’est pas un changement des autorisations.

## Planifié, hors maquettes

- Photo personnelle facultative : planifiée, aucun upload membre représenté.
- Compagnons de visite V2, recherche géographique ou par âge, filtres avancés : non implémentés et exclus.
- Signalement de profils : différé ; seuls les échanges sont signalables.
- Groupes communautaires, pièces jointes / GIF, édition ou suppression de messages : exclus.
- Aucun écran indépendant « Univers croisés » : le composant existant est un dialogue.
- Aucune page admin Notifications : notifications accessibles dans les espaces membre / partenaire selon les rôles.

## Scénarios de revue

1. Accueil → inscription → profil → passer → découvrir → univers croisés → échange → installation.
2. Explorer → profil → Découvrir → dialogue → échange ; historique → profil en panneau → conversion.
3. Événements → détail privé → inscription → détail accepté → participants → profil → retour ; demandes organisateur et annulation.
4. Échange → signalement avec blocage → confirmation ; admin → signalement → motif → clôture ou bannissement.
5. Partenaire → brouillon bilingue → soumission figée ; admin → approbation avec envoi immédiat ; agrégats.
6. Compte → export / suppression ; sécurité → 2FA / passkeys ; notifications → appareil ; cookies → refus / retrait.
7. Même scénario en anglais, 320 px, sombre, Halloween et Noël ; lecture seule et droits insuffisants.
